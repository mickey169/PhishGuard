About PhishGuard

PhishGuard is a student cybersecurity project designed to demonstrate how phishing attacks can be identified and how users can improve their online safety.

Project Objectives

  • Identify suspicious email content.
  • Analyze URLs for potentially harmful characteristics.
  • Educate users about phishing attacks.
  • Maintain scan history and generate CSV reports.

Technologies Used

  • Python
  • Flask
  • HTML, CSS and JavaScript
  • SQLite
  • Pandas and Scikit-learn

Project Purpose

This project is developed for educational purposes as part of a cybersecurity internship project. It uses basic detection techniques to demonstrate phishing awareness and analysis.
